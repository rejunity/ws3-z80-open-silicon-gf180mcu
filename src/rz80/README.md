# RZ80

The Z80 core: `rtl/` of [rejunity/z80-from-schematics](https://github.com/rejunity/z80-from-schematics) at
[`193230c`](https://github.com/rejunity/z80-from-schematics/commit/193230c3b8eea06b65b7e1c79734a599418c23ad), unchanged, copied by
`scripts/sync_rz80.py` from the `rz80/` submodule.

at the top of this repository for the notices a product must carry.
